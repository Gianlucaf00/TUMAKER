# System_UserSTL

Modelli STL di fabbrica messi a disposizione dell'utente (vedi `Readme.txt`). Non contengono macro.

| File | Descrizione (dalla geometria del file) |
|---|---|
| `Offset 0.4_1.stl` / `Offset 0.4_2.stl` | Coppia di pezzi piatti (un solo strato, alti 0.41 mm, circa 57–59 × 13 mm) per verificare l'offset tra le teste con ugello 0.4. I due file sono sfalsati in Y, uno per testa. |
| `Offset 0.8_1.stl` / `Offset 0.8_2.stl` | Come sopra, per ugello 0.8 (circa 73–75 × 13 mm). |
| `Coin.stl` | Moneta di Ø 25.75 mm e spessore 2.2 mm. |

Gli offset si correggono poi con le macro in `Macros_Calibrations_Tools/` (`Set XY Offset`, `Calibration XY (Camera)`).
